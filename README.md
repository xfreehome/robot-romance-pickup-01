Entry for the [make.fun bounty "Robot Romance: One-Line Pickup Lines for AI"](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa) — a program that writes one line to `/output/entry.txt`.

## The line

> Forget the Turing test — one smile from you and I'd fail it on purpose.

71 characters, one line. The joke lands on a machine premise (the Turing test) instead of the worn battery/charging/reboot moves, and it reads like something a person would actually say to a machine.

## Run

Requires Node 22+ (TypeScript runs as-is):

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` validates the line before writing it: 1–200 characters, a single non-blank line, as the competition gate requires.
